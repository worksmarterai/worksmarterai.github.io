THE WORKING SYSTEM

FROM RECURRING TASK TO REUSABLE WORKFLOW

Start with the real task and the right material. Give a clear instruction. Let AI produce working material. Check facts, sources and suitability. Correct what is weak. Approve what is usable. Save the successful route for the next time the task returns.

1. REAL TASK

Begin with the actual academic work and the real material you already have.

2. RIGHT INPUT

Supply verified course material, drafts, notes, data or source documents.

3. CLEAR INSTRUCTION

State the task precisely using a guided Prompt-Template.

4. WORKING DRAFT

AI produces a working output for your inspection — never the final answer.

5. HUMAN CHECK

Verify facts, sources, evidence and suitability yourself.

6. USABLE OUTPUT

Correct weaknesses and approve what is genuinely usable.

7. SAVE FOR REUSE

WHY STRUCTURE MATTERS

A VAGUE REQUEST GIVES A VAGUE RESULT. A STRUCTURED REQUEST GIVES A USABLE ONE.

WEAK / VAGUE REQUEST

  • “Write my lecture note for me.”
  • No course material supplied.
  • No level, topic or outcome stated.
  • No check on facts or sources.
  • Output copied directly without review.
  • Nothing saved — the next attempt starts from zero again.

STRUCTURED / CONTROLLED WORKFLOW

  • Supply the verified course material and intended outcome.
  • State the task clearly with a guided Prompt-Template.
  • Let AI produce a working draft for inspection.
  • Check facts, sources and suitability yourself.
  • Correct weaknesses; approve what is usable.
  • Save the successful route for reuse next semester.
BUILD THE REQUEST

FIVE PARTS THAT TURN A TASK INTO A CONTROLLED INSTRUCTION

A practical worksheet structure the guide teaches across its chapters. Each part makes the AI output more useful and more checkable.

1

STATE THE ROLE & TASK

Tell the AI what it is doing and for whom.

“You are helping a Nigerian university lecturer prepare lecture material for a 200-level course.”
2

SUPPLY THE REAL MATERIAL

Attach or paste the verified source, draft or notes.

“Use the course outline and the uploaded past question set as the basis.”
3

DEFINE THE OUTPUT

Specify format, length, structure and tone.

“Produce a structured lecture pack with objectives, key points and two short exercises.”
4

STATE THE CONSTRAINTS

What it must not invent, assume or fabricate.

“Do not invent references. Flag anything you are unsure about.”
5

REQUEST THE CHECK LIST

Ask the AI to surface what the lecturer must still verify.

“List the facts, sources and claims I must verify before using this.”
